# Web-дизайн

Цей репозиторій містить матеріали та практичні роботи з навчальної дисципліни **Web-дизайн**.

## Опис дисципліни

Предмет навчальної дисципліни – в даному курсі розглядаються основні технології розробки веб-сторінок, а саме:

- HTML – мова розмітки для створення структури веб-сторінки
- CSS – мова стилів для оформлення веб-сторінки
- JavaScript – мова програмування для створення інтерактивності

## Мета курсу

Метою дисципліни є отримання базових знань та практичних навичок створення сучасних веб-сайтів.

## Структура репозиторію

Репозиторій може містити:

- практичні роботи
- приклади HTML-сторінок
- CSS стилі
- JavaScript скрипти

## Технології

У проєкті використовуються:

- HTML
- CSS
- JavaScript
